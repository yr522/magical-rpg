# 균열의 계약자 (마법소녀/소년 텍스트 RPG)

기획서: [마법소녀 소년 텍스트 RPG 기획서.md](./마법소녀%20소년%20텍스트%20RPG%20기획서.md)

**지금까지 만든 기능과 콘텐츠 종합: [docs/현재까지-만든-것.md](./docs/현재까지-만든-것.md)**

## 지금 되는 것 (로드맵 1~3단계 + 4단계 일부)

**1~2단계: 접속 · 탐사**
- 회원가입 / 로그인 (닉네임 + 비밀번호, 비밀번호는 해시로 저장)
- 캐릭터 선택 · 생성 · 삭제 (계정당 최대 5개), 스탯 미리보기
- 본부 4구역 + 공원 균열 6구역 이동, 둘러보기, 지도
- 같은 구역 유저 목록, 지역 채팅, 전체 채팅
- 끊겨도 30초 동안 유지 → 새로고침하면 그 자리로 복귀

**3단계: 전투 · 성장**
- 테스트용 상시 토벌 이벤트: **공원 균열 › 균열의 중심**의 덩굴 포식자 (제한시간 없음, 잡아도 다시 나타남)
- 턴제 전투: 민첩(AGI) 높은 순서로 차례. 내 차례에 공격 / 스킬 / 아이템 / 도주 (차례 제한시간 없음. 연결이 끊기면 30초 뒤 전투에서 빠짐)
- 한 전투에 최대 4명, 진행 중에도 합류 가능 (다음 라운드부터 행동)
- 데미지 공식, 몬스터 속성 저항 (취약 ×1.5 / 내성 ×0.5 / 면역 ×0), 회피, 치명타
- 클래스별 스킬 4개 (레벨로 해금, MP 소모, 쿨다운)
- 몬스터 AI: 도발한 사람 → 가장 많이 때린 사람 또는 무작위, 3턴마다 강한 공격
- 전투 화면: 위에 적, 가운데 메뉴, 좌우에 참가자 4칸, 전투 채팅은 프사 옆 말풍선
- 승리: 경험치·골드를 참가 인원수로 나눔, 아이템은 각자 확률 드롭 → 레벨업 시 스탯 포인트 3점 + HP/MP 전체 회복
- 전멸: 본부로 귀환, 보유 골드 10% 손실 (이벤트는 그대로 남음)
- 캐릭터 메뉴에서 스탯 분배, 스킬·소지품 보기
- 본부에 들어오면 HP/MP 전체 회복
- 새 캐릭터는 회복 사탕 3개를 가지고 시작

**4단계 일부: 인벤토리 · 상점 · 장비** (1:1 직거래는 아직)
- 장비 6칸: 무기 / 의상 / 장신구 / 머리장식 / 신발 / 장신구 2. 장착하면 스탯이 오르고, 전투에도 바로 반영
- 새 캐릭터는 기본 장비(견습 마법봉 · 견습 리본 · 견습 브로치)를 끼고 시작. 예전 캐릭터도 다음 접속 때 한 번 받음
- 장비 등급: 드롭될 때 등급이 정해지고, 등급 배율만큼 스탯이 오름. 고급 이상은 무작위 추가 옵션
- 덩굴 포식자가 장비 4종을 서로 다른 확률로 떨어뜨림 (일반·고급 등급만)
- 인벤토리: 장착 / 벗기 / 사용 / 분해(균열 파편) / 버리기
- 본부 상점: 구매 / 판매. 사는 값은 비싸고 파는 값은 싸다 (기본 40%)
- 골드·아이템 변경은 한 번에 저장되고, 빠르게 여러 번 눌러도 복사되지 않음

**그 뒤로 만든 것**: OC 프로필(사진 2장 · 칭호 · 설정 글 · 관계 · 대사 프리셋), 친구 · 관계, 파티와 같이 토벌 입장, 초대 코드 가입과 관리자 모드, 데미지 숫자 연출. 자세한 건 [종합 문서](./docs/현재까지-만든-것.md).

아직 없는 것: 1:1 직거래, 시간제한 토벌 이벤트와 지역 파괴(5장), 다른 지역, 퀘스트, 폰 화면.

**덩굴 포식자 장비 드롭 확률 (한 번 잡을 때 각각 따로 굴림)**

| 장비 | 확률 | 등급 |
| --- | --- | --- |
| 덩굴 낫 (무기, STR+3 AGI+1) | 30% | 일반 약 66% / 고급 약 34% |
| 잎사귀 망토 (의상, VIT+3) | 30% | 〃 |
| 가시덩굴 마법봉 (무기, MAG+4) | 15% | 〃 |
| 초록 핵 브로치 (장신구, MAG+1 LUK+3) | 8% | 〃 |

한 번 잡으면 장비가 하나 이상 나올 확률은 약 73%.

알아 둘 점: 전투 도중에 서버가 재시작되면 그 전투는 사라지고, 캐릭터는 전투 들어가기 전 상태로 돌아간다. (전투 중에 쓴 아이템은 그대로 없어진다.)

## 1. 내 컴퓨터에서 테스트하기

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 버전 설치 추천)

```bash
git clone https://github.com/yr522/magical-rpg.git
cd magical-rpg
npm install
npm start
```

`http://localhost:3000 에서 실행 중`이 뜨면 브라우저에서 <http://localhost:3000> 을 연다.
DB 설정이 없어도 `data/local-db.json` 파일에 저장되면서 돌아간다.

**혼자서 두 명 흉내 내기**: 일반 창 하나 + 시크릿 창 하나를 열고 각각 다른 닉네임으로 가입하면,
서로 같은 구역에 보이고 채팅이 오가는지 확인할 수 있다.

**같은 와이파이의 폰으로 접속**: 컴퓨터의 내부 IP(예: `192.168.0.12`)를 확인한 뒤
폰 브라우저에서 `http://192.168.0.12:3000` 으로 접속한다. (방화벽이 막으면 허용)

### 확인해 볼 체크리스트

1. 회원가입 → 로그아웃 → 같은 닉네임/비밀번호로 로그인
2. 캐릭터 만들기: 클래스·계약 신을 바꾸면 스탯 미리보기가 바뀌는지
3. 캐릭터 시작 → 본부 광장에 도착
4. 다른 창의 캐릭터가 "이곳의 계약자" 목록에 보이는지, 지역 채팅이 서로 보이는지
5. 한 명이 `남쪽 성문 · 공원 균열`로 이동 → 다른 쪽 목록에서 사라지고, 지역 채팅은 안 보이고, **전체** 채팅은 보이는지
6. 게임 중에 새로고침 → 같은 캐릭터, 같은 장소로 돌아오는지
7. 창을 닫으면 상대 화면에 "(자리 비움)" → 30초 뒤 "떠났다"
8. 서버를 껐다 켜도 캐릭터와 마지막 위치가 남아 있는지

### 3단계 전투 체크리스트

1. 본부 광장 → `남쪽 성문` → `동쪽 · 산책로` → `남쪽 · 숲길` → `남쪽 · 균열의 중심`으로 이동하면 `⚔ 입장 · 덩굴 포식자` 버튼이 보이는지
2. `토벌 목록`에 이벤트가 보이고 남은 시간이 "무기한"인지
3. 입장하면 변신 문장이 뜨고, 내 차례에 공격 / 스킬 / 아이템 / 방어 / 도주가 되는지
4. 스킬을 쓰면 MP가 줄고, 다음 차례에는 "N턴 뒤 사용 가능"으로 잠기는지
5. 내 차례에 아무것도 안 눌러도 차례가 넘어가지 않는지 (창을 닫으면 30초 뒤 전투에서 빠지는지)
6. 다른 창의 캐릭터가 같은 전투에 합류할 수 있는지, 전투 채팅이 상대 프사 옆 말풍선으로 뜨는지
7. 이기면 결과창에 경험치·골드·아이템이 나오고, 레벨이 오르면 캐릭터 메뉴에서 `+` 버튼으로 스탯을 올릴 수 있는지
8. 도주가 되고, 본부로 돌아가면 HP/MP가 회복되는지
9. 계속 `방어`만 눌러 일부러 지면 본부로 옮겨지고 골드가 10% 줄어드는지

### 인벤토리 · 상점 체크리스트

1. 새 캐릭터를 만들고 하단 `인벤토리`를 열면 견습 장비 3개가 "장착 중"에 있는지
2. `캐릭터` 메뉴에서 스탯 옆에 "(장비 +1)"이 보이는지, 장비를 벗으면 스탯과 최대 HP가 줄어드는지
3. 본부 광장 → `동쪽 · 상점` → `🛒 본부 상점`에서 회복 사탕을 사면 20 G가 줄고, 판매 탭에서 팔면 8 G만 들어오는지
4. 장착 중인 장비는 판매 목록에 안 나오고, 벗으면 나오는지
5. 덩굴 포식자를 몇 번 잡아서 장비를 얻고(결과창에 `[일반]`/`[고급]`), 인벤토리에서 장착되는지. 같은 칸 장비는 자동으로 바뀌는지
6. 장비를 분해하면 균열 파편이 생기는지, 버리기가 되는지
7. 고급 장비가 같은 이름의 일반 장비보다 스탯이 높고 비싸게 팔리는지

자동 테스트도 있다: `npm test`

## 2. 인터넷에 올려서 지인과 테스트하기 (무료)

### ① Supabase (DB)

1. <https://supabase.com> 가입 → **New project** (비밀번호는 따로 적어 두기, 지역은 **Southeast Asia (Singapore)** — Render 서버와 같은 곳이어야 빠르다)
2. 프로젝트 화면 위쪽의 **Connect** 버튼 → **Session pooler** 탭의 연결 주소를 복사
   - `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-...pooler.supabase.com:5432/postgres` 모양
   - `[YOUR-PASSWORD]` 자리에 1번에서 정한 비밀번호를 넣는다
   - **Direct connection 주소는 쓰지 말 것** (Render 무료에서 접속이 안 될 수 있음)
3. 테이블은 만들 필요 없다. 서버가 처음 켜질 때 자동으로 만든다.

### ② Render (게임 서버)

1. <https://render.com> 에 GitHub 계정으로 가입
2. **New → Blueprint** → `yr522/magical-rpg` 저장소 선택 → 브랜치 선택
   (이 저장소의 `render.yaml`을 읽어 설정이 자동으로 채워진다. 서버 위치도 싱가포르로 정해진다)
3. `DATABASE_URL` 칸에 ①에서 복사한 주소를 붙여 넣고, `ADMIN_CODE` 칸에 나만 아는 비밀 코드를 적고 **Apply**
   (그 다음 닉네임 `admin`, 초대 코드 칸에 그 비밀 코드를 적어 가입하면 관리자 계정이 된다)
4. 배포가 끝나면 `https://magical-rpg-xxxx.onrender.com` 같은 주소가 생긴다. 이 주소를 지인들에게 공유

서버 로그에 `저장소: Postgres (DATABASE_URL)`가 보이면 Supabase에 잘 연결된 것이다.
Supabase 대시보드의 **Table Editor**에서 `users`, `characters` 테이블에 가입한 계정이 쌓이는 것도 볼 수 있다.

### ③ 잠들기 방지 (선택이지만 추천)

Render 무료 서버는 15분 동안 아무도 없으면 잠들고, 깨어나는 데 1분쯤 걸린다.
<https://uptimerobot.com> 에서 무료 HTTP 모니터를 만들고 주소를 `https://(내 주소)/health`, 간격 5~10분으로 정하면 계속 깨어 있다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `server/index.js` | 서버 진입점. 접속·로그인·캐릭터·이동·채팅 처리 |
| `server/game.js` | 캐릭터 생성 규칙, 스탯 공식, 맵 검사 |
| `server/db.js`, `server/schema.sql` | 저장소 (Supabase Postgres 또는 로컬 파일) |
| `server/auth.js` | 비밀번호 해시, 로그인 토큰 |
| `server/data/character.json` | 성별·속성·클래스·계약 신·시작 스탯 (**수치 조정은 여기서**) |
| `server/data/map.json` | 지역과 구역, 묘사 문장, 출구 (**맵 추가는 여기서**) |
| `server/battle.js` | 턴제 전투 (차례 진행, 데미지, 스킬, 몬스터 AI) |
| `server/data/monsters.json` | 몬스터 스탯, 속성 저항, 드롭 |
| `server/data/skills.json` | 클래스별 스킬 |
| `server/data/items.json` | 아이템 (지금은 소모품과 재료만) |
| `server/data/events.json` | 고정 토벌 이벤트 |
| `server/data/shops.json` | 상점 (파는 물건, 살 때·팔 때 가격 배율) |
| `public/` | 브라우저 화면 (HTML/CSS/JS) |
| `test/` | 자동 테스트 |

`map.json`에 구역을 추가할 때는 양쪽 구역 모두에 출구를 적어야 한다.
한쪽만 적으면 서버가 켜질 때 어떤 구역이 문제인지 알려 주고 멈춘다.
