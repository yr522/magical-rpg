# 화면 시안 파일

기획자와 확정한 화면 시안의 사본. 설명은 `../ui-design.md`에 있다.
원본은 디자인 캔버스(https://claude.ai/artifact/UYdUgA9BX6qEAt3C7q6G9z)이고, 이 파일들은 그곳에서만 그대로 열린다.
게임에 옮길 때 크기 · 색 · 간격 값을 여기서 가져온다.

| 파일 | 화면 |
| --- | --- |
| Main.dc.html | 필드 화면 |
| Battle.dc.html | 전투 화면 (아래 줄) |
| BattleScene.dc.html | 전투 전경 |
| BattleSizes.dc.html | 전투 전경 인원별 비교 (1~4명) |
| Profile.dc.html | OC 프로필 창 (보기 · 편집) |
| Inventory.dc.html | 인벤토리 창 |
| Status.dc.html | 스테이터스 창 |
| Party.dc.html | 파티 창 |
| Shop.dc.html | 상점 창 |
| Raids.dc.html | 토벌 목록 창 |
