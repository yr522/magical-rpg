# 화면 설계 (확정본)

기획자와 함께 시안으로 확정한 화면 배치. 화면을 만들거나 고칠 때 이 문서를 기준으로 한다.
시안: https://claude.ai/artifact/UYdUgA9BX6qEAt3C7q6G9z (기획자 계정에서만 열림)
시안 파일 사본: `docs/mockups/` (화면 하나당 파일 하나. 실제 게임에 옮길 때 크기·색·간격을 여기서 그대로 가져온다)

## 공통 — 2026-10-19 확정

- **화면 비율**: 위 전경 : 아래 줄 = 7 : 3 (PC 기준 전경 560px, 아래 줄 240px).
- **프로필 사진은 두 장**을 받는다.
  1. **정사각형 프사**: 프로필 카드, 채팅, 3~4명 전투의 컷에 쓴다.
  2. **반신 컷인 이미지**: 1~2명 전투의 긴 컷에 쓴다 (스킬 컷인처럼 크게 드러남).
- **글씨체**: 전경 위 큰 글씨(맵 이름, 전투 참가자 이름 등)는 고운바탕 굵게, 흰 글씨에 검은 테두리.
- 폰 화면은 아직 정하지 않았다.
- **팝업 창 공통** (프로필 · 인벤토리 · 스테이터스 · 파티 등)
  - 화면을 꽉 채우지 않는 크기로 가운데에 뜨고, 뒤 화면은 어둡게 깔린다.
  - 닫기 버튼은 **창 안쪽 오른쪽 위**에 작은 흰색 `×` (18px, 동그라미·테두리 없음).
  - 제목 근처에 한 가지 색 장식선 `── ✦ ──` (그라데이션 없음).
  - 장비 테두리 색 = 희귀도 색 (`items.json`의 `grades.color`).

### 아래 줄 (필드·전투 공통 틀, 왼쪽부터)
1. **채팅** (넓은 칸)
   - 위에 채널 탭. 탭을 누르면 그 채널을 보이기/숨기기 (켜짐은 색, 꺼짐은 회색. ON/OFF 글씨는 없음).
   - 메시지 한 줄: 작은 프사 + `[채널] 이름: 내용`.
   - 아래에 보낼 채널 선택 + 입력칸 + 전송.
2. **프로필 카드 + 행동 버튼** (테두리 하나로 묶인 한 칸, 안쪽은 칸 나눔 없음)
   - **프로필 카드(왼쪽)**: 왼쪽 위 `Lv.3`, 가운데 둥근 프사(크게), 그 아래 `[칭호]`, 이름.
     HP · MP · 경험치 막대는 **카드 맨 아래에 붙인다** (이름과 간격을 둠).
     막대는 얇고 네모난 모양(테두리 없음), 양옆 여백을 줄여 길게. 골드는 여기 없고 인벤토리에서 본다.
   - **행동 버튼(오른쪽)**: 아이콘 위 + 글씨 아래의 둥근 타일 버튼. 프로필 카드와 간격을 두고, 가장자리 여백을 둔다.
3. **아이콘 메뉴** (오른쪽 끝, 작은 아이콘 한 줄 세로): 위에서부터 장비 / 인벤토리 / 스테이터스 / 프로필(OC 프로필) / 파티·친구 / 설정
   - **설정**을 누르면 설정 버튼 왼쪽으로 노란 테두리 상자가 펼쳐진다: 음향(아직 기능 없음) / 테마(밝게·어둡게) / 캐릭터 변경 / 로그아웃.
- **맨 아래 상태 줄**: `v.1 ● · n명 접속 중` (●는 서버 연결 상태: 초록=좋음, 주황=불안정, 빨강=끊김).

## 필드 화면 (PC) — 2026-10-19 확정

전투가 아닌 일반 맵 화면.

### 맵 전경
- **맵 이름**: 왼쪽 위, `지역 이름 - 맵 이름`.
- **배경**: 지금은 맵마다 색(그라데이션)으로만. 나중에 배경 그림으로 바꾼다.
- **바닥(땅)**: 전경 아래쪽 띠. 나중에 캐릭터 스탠딩이 이 위에 서고, 원하는 자리로 움직이며 실시간으로 보인다.
- **파티 정보** (파티에 들어가 있을 때만): 왼쪽 위, 맵 이름 아래 (전경 위에서 142px). **나 포함** 한 사람당 한 칸.
  - 칸: 반투명 검정 배경, **외곽선 없음**. 왼쪽에 둥근 프사.
  - 윗줄: `Lv.3 이름` (내 이름은 연보라색, 파티장은 이름 뒤 👑). 아랫줄: 현재 위치 (작은 글씨 10px, 아이콘 없음).
- **같은 구역 사람 버튼**: 오른쪽 위. 사람 모양 + 인원수. 누르면 전경 안에서만 반투명 검정 상자가 펼쳐지고, 다시 누르면 접힌다. 한 줄 형식: `Lv.3 [칭호] 이름` (칭호가 없으면 대괄호 없이).
- **바닥 글 상자**: 장소 묘사, 둘러보기 결과, NPC 대사, 선택지가 뜨는 곳. 평소에는 안 보이고 글이 있을 때만 나타난다.
  - 검정 반투명 배경, 가장자리가 검게 번지며 흐려짐, 뒤 배경 살짝 흐림 (흰 테두리 없음)
  - 위아래 여백은 아주 조금, 좌우는 넉넉하게
  - 글: 흰색, 가운데 정렬, 작고 얇게 (14px, 얇은 두께), 글이 들어가는 폭은 최대 560px
  - 선택지(1. 들어간다 2. 물러난다 등)는 글 오른쪽에. 선택지가 없을 때는 오른쪽에 작은 X(닫기)
  - 지나간 글은 [시스템] 채팅에 남는다

### 아래 줄
- **채팅 탭**: [서버] [지역] [시스템]. 보낼 채널은 지역/서버. ("전체" 채팅은 "서버"로 부른다.)
- **행동 버튼**: 그 장소에서 할 수 있는 일 (이동, 둘러보기, 토벌 목록, 상점 등). 한 줄에 3개씩 타일.
  - **이동**을 누르면 버튼들이 출구 목록 타일로 바뀌고, [뒤로]로 돌아온다. 이동 버튼을 맵 위에 두지 않는다 (잘못 누르기 쉽고 방향이 헷갈림).
  - 토벌 이벤트가 있는 곳에서는 빨간 **토벌 입장** 버튼. 누르면 바닥 글 상자에 선택지가 뜬다.

## 전투 화면 (PC) — 2026-10-19 확정

### 전투 전경
- **왼쪽 위**: 맵 이름. **오른쪽 위**: `3라운드 · 이름의 차례 · 23초` 상자 (차례 부분은 노란 글씨).
- **가운데**: 적 이름 + `Lv`, 그 아래 적 HP 막대 (숫자는 안 보임), 그 아래 적 그림.
- **바닥 글 상자**: 전투 기록 최신 한 줄 (필드의 바닥 글 상자와 같은 모양).
- **참가자 컷**: 전경 양옆에 사다리꼴 컷. **좌 우 좌 우** 순서로 놓는다.
  - **1~2명**: 한쪽에 컷 하나씩 길게. **반신 컷인 이미지**가 위(얼굴)부터 컷을 꽉 채워 스킬 컷인처럼 드러난다.
  - **3~4명**: 한쪽에 위아래 두 칸씩 짧게. **정사각형 프사**가 컷 아래쪽에 들어간다.
  - **이름**: 컷 아랫면 경계에 걸쳐서, 크게 굵게 테두리 글씨. 내 캐릭터는 `이름 (나)`.
  - **HP**: 막대가 따로 없다. 줄어든 HP만큼 **사진 아래에서부터 붉은 반투명 그라데이션**이 차오른다 (항상 사진 위에 덮임). MP는 전경에 표시하지 않는다.
  - **쓰러짐**: 글씨 없이 사진이 흑백·어둡게.
  - **지금 차례인 사람**: 컷 테두리가 두꺼운(4px) 노란 빛으로 바뀌고, 하얗게 빛나는 작은 점 하나가 테두리를 따라 LED처럼 돈다. 차례가 아닌 사람은 테두리 없음.
  - **말풍선**: 전투 채팅에 쓴 말이 그 사람 컷 옆(가운데 쪽)에 5초간 뜬다.

### 아래 줄
- **채팅**: [전투 채팅] 탭 하나. 전투 참가자끼리만 보인다.
- **행동 버튼** (방어는 없음):

  ```
  ┌──────────────┐ ┌─────────┐
  │     스킬     │ │  공격   │   윗줄 높이 2/3  (스킬 : 공격 폭 = 3 : 2)
  │              │ │         │
  └──────────────┘ └─────────┘
  ┌─────────────────────┐ ┌──┐
  │        아이템        │ │도주│ 아랫줄 높이 1/3 (도주는 정사각형, 오른쪽 아래 끝.
  └─────────────────────┘ └──┘                    아이템이 남은 폭을 다 채움)
  ```
  - 도주는 흐린 색으로 다른 버튼보다 눈에 덜 띄게.
  - **스킬**을 누르면 버튼들이 내 스킬 목록 타일로 바뀌고, [뒤로]로 돌아온다.
  - **내 차례가 아니면** 모든 버튼이 흐려지고 눌리지 않는다.

## OC 프로필 창 (PC) — 2026-10-19 확정

화면을 꽉 채우지 않는 **팝업 크기**의 창 (시안 기준 1040 × 640px). 뒤 화면은 어둡게 깔린다.
프로필 아이콘, 채팅의 이름·프사, 관계 칸을 누르면 열린다.

### 보기 (내 프로필 / 다른 사람 프로필)
가로로 넓은 카드 한 장. 오른쪽 아래 모서리를 비스듬히 자른다. 오른쪽 위 바깥에 닫기(×).

```
┌──────────┬────────────────────────────┬──────────┐
│          │   ─────── ✦ ───────        │ [관계]    │
│ 반신     │                            │ 릴리 소꿉친구│
│ 컷인     │   이름 (크게)               │ (5줄, 넘치면│
│ 사진     │   [칭호]                    │  스크롤)  │
│          │   Lv.3 (속성) 클래스 · 성별  │           │
│          │                            │ 장비      │
│          │   OC 설정 글 (배경 없이 글자만)│ □ □      │
│          │                            │ □ □      │
│          │   [프로필 편집]              │ □ □     /│
└──────────┴────────────────────────────┴────────/─┘
```
- **반신 컷인 사진**: 왼쪽·위·오른쪽에 여백, 아래는 카드 바닥에 닿는다. 흐림·그라데이션 없음. 기본 프사를 쓰면 기본 그림.
- **장식선**: 이름 위에 `── ✦ ──`, 한 가지 색(그라데이션 없음).
- **간격**: 장식선 → 이름 간격과, 정보 묶음 → 설명 글 간격을 똑같이 맞춘다.
- **정보 묶음**: 이름(고운바탕, 크게) → 아래 줄에 `[칭호]` → 그 아래 한 줄에 `Lv.3` · 속성 아이콘(테두리 = 속성 색) · 클래스 · 성별.
- **OC 설정 글**: 배경 상자 없이 글자만. 길면 그 자리에서 스크롤.
- **버튼** (설명 글 아래): 내 프로필은 [프로필 편집]. 다른 사람은 [친구 신청] [관계 신청] (관계 신청은 친구가 된 뒤에만 눌림).
- **관계 칸**: "관계" 제목 + 한 줄에 `이름 · 관계 이름`. 5줄까지 보이고 넘치면 칸 안에서 스크롤. 누르면 그 사람 프로필로.
- **장비 칸**: 2칸 × 3줄 = 6칸 (무기 / 의상 / 장신구 / 머리장식 / 신발 / 장신구 2). 장비 그림만 보이고 **테두리 색 = 희귀도 색** (`items.json`의 `grades.color`). 마우스를 올리면 이름 · 종류 · 희귀도 · 능력치가 작은 창으로 뜬다. 빈 칸은 점선.

### 편집
왼쪽에 항목 탭, 오른쪽에 내용, 아래에 [취소] [저장].
- **기본 정보**: 이름 (서버 안 다른 캐릭터와 겹치면 안 됨, [중복 확인] 필수) / 칭호 (얻은 칭호 중에서 고르기) / 성별 (마법소녀·마법소년).
- **사진**: [기본 프사 쓰기] 또는 [커스텀 사진 쓰기]. 커스텀이면 **① 정사각형 프사 ② 세로로 긴 반신 컷인 사진 두 장을 모두 올려야** 저장된다.
- **OC 설정**: 큰 글상자 한 칸에 자유롭게 (외형·성격·과거 등을 나누지 않음).
- **관계**: 내 관계 목록(성립 / 수락 기다리는 중 / 받은 신청 [수락]) + 해제·취소·거절. 새 관계는 **친구 목록에서** 한 명 고르고 관계 이름을 적어 신청 → 상대가 수락하면 두 사람 프로필에 모두에게 보인다. 미리보기: `세라와 릴리는 소꿉친구 관계`.
- **대사 프리셋**: 상황마다 최대 3개, 여러 개면 무작위로 하나. 비우면 말없이 진행.

### 임시로 정한 값 (게임에 넣을 때 README "임시로 정한 규칙"에도 적는다)
- 대사 상황 7가지: 전투 시작(변신) / 공격할 때 / 스킬 쓸 때 / 다쳤을 때 / 회복받았을 때 / 쓰러졌을 때 / 승리했을 때 (기획서의 "스킬마다 따로"는 일단 하나로 묶음)
- 글자 수: 이름 12자, 관계 이름 12자, 대사 한 줄 40자, OC 설정 2000자
- 컷인 사진 비율: 가로 1 : 세로 2
- 기본 프사: 일단 그림 하나
- 장비 부위 6개로 늘림 (기획자 결정): 머리장식 · 신발 · 장신구 2 추가

## 인벤토리 창 (PC) — 2026-10-19 확정

팝업 728 × 448px.
- **오른쪽: 가방** — 장식선 아래 한 줄에 5칸 (52px), 칸이 많으면 그 안에서 스크롤. 칸에는 아이템 그림, 2개 이상이면 오른쪽 아래에 개수. 장비 칸 테두리 = 희귀도 색. 빈 칸은 점선. 아래에 `사용 칸 / 100칸`과 **보유 골드**. 가방은 **최대 100칸**.
- **왼쪽: 고른 아이템** — 칸을 누르면 선택(보라 테두리)되고, 큰 그림 · 이름 · `희귀도 · 종류` · 설명 · **습득처** · **판매가** (본부 상점 기준)가 나온다.
- **행동 버튼** (설명 아래): 소모품 [사용] [버리기] / 장비 [분해] [버리기] (장비는 보이지만 **여기서 낄 수 없다** — 장비 창에서) / 재료 [버리기].
- 가방에는 **안 낀 장비만** 보인다. 장비는 같은 장비여도 **겹치지 않고 한 칸씩**, 소모품·재료는 같은 종류끼리 한 칸.

- **왼쪽**: `장비` 제목 아래 지금 낀 장비 2칸 × 3줄 (무기 / 의상 / 장신구 / 머리장식 / 신발 / 장신구 2), 테두리 = 희귀도 색, 빈 칸은 점선. 옆에 고른 장비의 이름 · `희귀도 · 부위` · 설명 · 능력치.

## 파티 창 (PC) — 2026-10-19 확정

팝업 480 × 400px. 파티는 **최대 4명** (전투 인원과 같음).
- **머리**: 파티 이름 (기본값 `만든 사람 이름 + 의 파티`), 오른쪽에 `n / 4명`, 아래 장식선.
- **멤버 목록** (파티장이 맨 위, 파티장 줄 왼쪽에 노란 선 + `👑 파티장`): 둥근 프사 · 이름 (내 이름은 보라색, "(나)" 글씨 없음) · 아랫줄 `Lv · 클래스 · 📍 위치` · 오른쪽 상태 점.
  - 상태: 🟢 접속 중 / 🔴 전투 중 / 회색 오프라인 (오프라인은 프사 흑백, 위치는 마지막 위치).
- **우클릭 메뉴** (다른 데 누르면 사라짐)
  - 나: [파티 나가기]
  - 다른 사람: 내가 파티장일 때만 [파티장 위임] [추방]. 파티장이 아니면 메뉴 없음.
- **초대**: 오른쪽 아래 작은 [+ 초대] → 캐릭터 이름 적는 작은 팝업.
  - 접속 중이면 초대가 가고, 상대가 수락하면 들어온다.
  - 오프라인이면 "캐릭터가 오프라인입니다." / 없는 이름 · 이미 파티원 · 4명 가득도 각각 알려 준다.
- **파티 이름 바꾸기**: 이름 오른쪽 작은 ⚙ 아이콘 (파티장만 보임) → 그 자리에 입력칸 + [저장]. 엔터나 [저장]으로 바뀐다. 최대 16자, 비우면 기본 이름.
- 임시로 정한 것: 파티장이 나가면 남은 사람 중 다음 사람이 파티장이 된다.
