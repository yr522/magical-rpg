# 화면 설계 (확정본)

기획자와 함께 시안으로 확정한 화면 배치. 화면을 만들거나 고칠 때 이 문서를 기준으로 한다.
시안: https://claude.ai/artifact/UYdUgA9BX6qEAt3C7q6G9z (기획자 계정에서만 열림)

## 필드 화면 (PC) — 2026-10-19 확정

전투가 아닌 일반 맵 화면. 폰 화면은 아직 정하지 않았다.

```
┌──────────────────────────── 맵 전경 ────────────────────────────┐
│ 지역 이름 - 맵 이름 (테두리 글씨)                    [사람 n] │
│ (나중에) 파티원 목록                              (목록 펼침)   │
│                                                                 │
│                      (나중에) 캐릭터 스탠딩                     │
│ ──────────────────────── 바닥(땅) ──────────────────────────── │
│            [ 바닥 글 상자: 묘사 · 대사 · 선택지 ]               │
└─────────────────────────────────────────────────────────────────┘
┌──── 채팅 ────┐ ┌─ 행동 메뉴 ─┐ ┌─ 프로필 ─┐ ┌유저 메뉴┐ ┌시스템┐
│[서버][지역]  │ │ 이동        │ │ Lv.3     │ │ 장비    │ │친구  │
│[시스템] ON/OFF│ │ 둘러보기    │ │ (프사)   │ │ 인벤토리│ │음향  │
│ 메시지들     │ │ 토벌 목록   │ │ [칭호]   │ │스테이터스│ │테마  │
│[지역∨][입력][전송]│ │ (상점 등)  │ │ 이름     │ │ 프로필  │ │캐릭변경│
└──────────────┘ └─────────────┘ │ HP/MP/EXP│ └─────────┘ │로그아웃│
게임 버전 v.1 · 서버 연결 OK · 현재 n명 접속 중          └──────┘
```

### 맵 전경
- **맵 이름**: 왼쪽 위, `지역 이름 - 맵 이름`. 흰 글씨에 검은 테두리 (고운바탕 굵게).
- **배경**: 지금은 맵마다 색(그라데이션)으로만. 나중에 배경 그림으로 바꾼다.
- **바닥(땅)**: 전경 아래쪽 띠. 나중에 캐릭터 스탠딩이 이 위에 서고, 원하는 자리로 움직이며 실시간으로 보인다.
- **파티원 목록 (나중에, 파티 기능이 생기면)**: 왼쪽 위, **맵 이름 바로 아래**에 띄운다.
- **같은 구역 사람 버튼**: 오른쪽 위. 사람 모양 + 인원수. 누르면 전경 안에서만 반투명 검정 상자가 펼쳐지고, 다시 누르면 접힌다. 한 줄 형식: `Lv.3 [칭호] 이름` (칭호가 없으면 대괄호 없이).
- **바닥 글 상자**: 장소 묘사, 둘러보기 결과, NPC 대사, 선택지가 뜨는 곳. 평소에는 안 보이고 글이 있을 때만 나타난다.
  - 검정 반투명 배경, 가장자리가 검게 번지며 흐려짐, 뒤 배경 살짝 흐림 (흰 테두리 없음)
  - 위아래 여백은 아주 조금, 좌우는 넉넉하게
  - 글: 흰색, 가운데 정렬, 작고 얇게 (14px, 얇은 두께), 글이 들어가는 폭은 최대 560px
  - 선택지(1. 들어간다 2. 물러난다 등)는 글 오른쪽에. 선택지가 없을 때는 오른쪽에 작은 X(닫기)
  - 지나간 글은 [시스템] 채팅에 남는다

### 아래 줄 (왼쪽부터)
- **채팅**: 위에 [서버] [지역] [시스템] 켜기/끄기 버튼 (끄면 그 채널이 숨겨짐). 메시지 한 줄: 작은 프사 + `[채널] 이름: 내용`. 아래에 보낼 채널 선택(지역/서버) + 입력칸 + 전송. ("전체" 채팅은 "서버"로 부른다.)
- **행동 메뉴**: 그 장소에서 할 수 있는 일 버튼 모음 (이동, 둘러보기, 토벌 목록, 상점 등).
  - **이동**을 누르면 메뉴 칸이 "어디로 갈까?" 출구 목록으로 바뀌고, [뒤로]로 돌아온다. 이동 버튼을 맵 위에 두지 않는다 (잘못 누르기 쉽고 방향이 헷갈림).
  - 토벌 이벤트가 있는 곳에서는 맨 위에 빨간 **토벌 입장** 버튼. 누르면 바닥 글 상자에 선택지가 뜬다.
- **프로필 카드**: 왼쪽 위 `Lv.3`, 가운데 둥근 프로필 사진, 그 아래 `[칭호]`, 이름, 맨 아래 얇은 HP · MP · 경험치 막대 차례로. **골드는 여기 없고 인벤토리에서 본다.**
- **유저 메뉴** (큰 버튼 4개): 장비 / 인벤토리 / 스테이터스 / 프로필(OC 프로필)
- **시스템 메뉴** (작은 버튼 5개, 위에서부터): 친구·커뮤니티(친구 추가, 파티 초대) / 음향(아직 기능 없음) / 테마(밝게·어둡게) / 캐릭터 변경 / 로그아웃
- **맨 아래 상태 줄**: 게임 버전, 서버 연결 상태, 현재 접속 인원

## 아직 정하지 않은 화면
전투 화면, 장비 · 인벤토리 · 스테이터스 · 프로필 창, 친구 · 커뮤니티 창, 폰 화면.
