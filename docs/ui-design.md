# 화면 설계 (확정본)

기획자와 함께 시안으로 확정한 화면 배치. 화면을 만들거나 고칠 때 이 문서를 기준으로 한다.
시안: https://claude.ai/artifact/UYdUgA9BX6qEAt3C7q6G9z (기획자 계정에서만 열림)

## 공통 — 2026-10-19 확정

- **화면 비율**: 위 전경 : 아래 줄 = 7 : 3 (PC 기준 전경 560px, 아래 줄 240px).
- **프로필 사진은 두 장**을 받는다.
  1. **정사각형 프사**: 프로필 카드, 채팅, 3~4명 전투의 컷에 쓴다.
  2. **반신 컷인 이미지**: 1~2명 전투의 긴 컷에 쓴다 (스킬 컷인처럼 크게 드러남).
- **글씨체**: 전경 위 큰 글씨(맵 이름, 전투 참가자 이름 등)는 고운바탕 굵게, 흰 글씨에 검은 테두리.
- 폰 화면은 아직 정하지 않았다.

### 아래 줄 (필드·전투 공통 틀, 왼쪽부터)
1. **채팅** (넓은 칸)
   - 위에 채널 탭. 탭을 누르면 그 채널을 보이기/숨기기 (켜짐은 색, 꺼짐은 회색. ON/OFF 글씨는 없음).
   - 메시지 한 줄: 작은 프사 + `[채널] 이름: 내용`.
   - 아래에 보낼 채널 선택 + 입력칸 + 전송.
2. **프로필 카드 + 행동 버튼** (테두리 하나로 묶인 한 칸, 안쪽은 칸 나눔 없음)
   - **프로필 카드(왼쪽)**: 왼쪽 위 `Lv.3`, 가운데 둥근 프사(크게), 그 아래 `[칭호]`, 이름.
     HP · MP · 경험치 막대는 **카드 맨 아래에 붙인다** (이름과 간격을 둠).
     막대는 얇고 네모난 모양(테두리 없음), 양옆 여백을 줄여 길게. 골드는 여기 없고 인벤토리에서 본다.
   - **행동 버튼(오른쪽)**: 아이콘 위 + 글씨 아래의 둥근 타일 버튼. 프로필 카드와 간격을 두고, 가장자리 여백을 둔다.
3. **아이콘 메뉴** (오른쪽 끝, 작은 아이콘 한 줄 세로): 위에서부터 장비 / 인벤토리 / 스테이터스 / 프로필(OC 프로필) / 파티·친구 / 설정
   - **설정**을 누르면 설정 버튼 왼쪽으로 노란 테두리 상자가 펼쳐진다: 음향(아직 기능 없음) / 테마(밝게·어둡게) / 캐릭터 변경 / 로그아웃.
- **맨 아래 상태 줄**: `v.1 ● · n명 접속 중` (●는 서버 연결 상태: 초록=좋음, 주황=불안정, 빨강=끊김).

## 필드 화면 (PC) — 2026-10-19 확정

전투가 아닌 일반 맵 화면.

### 맵 전경
- **맵 이름**: 왼쪽 위, `지역 이름 - 맵 이름`.
- **배경**: 지금은 맵마다 색(그라데이션)으로만. 나중에 배경 그림으로 바꾼다.
- **바닥(땅)**: 전경 아래쪽 띠. 나중에 캐릭터 스탠딩이 이 위에 서고, 원하는 자리로 움직이며 실시간으로 보인다.
- **파티원 목록 (나중에, 파티 기능이 생기면)**: 왼쪽 위, **맵 이름 바로 아래**에 띄운다.
- **같은 구역 사람 버튼**: 오른쪽 위. 사람 모양 + 인원수. 누르면 전경 안에서만 반투명 검정 상자가 펼쳐지고, 다시 누르면 접힌다. 한 줄 형식: `Lv.3 [칭호] 이름` (칭호가 없으면 대괄호 없이).
- **바닥 글 상자**: 장소 묘사, 둘러보기 결과, NPC 대사, 선택지가 뜨는 곳. 평소에는 안 보이고 글이 있을 때만 나타난다.
  - 검정 반투명 배경, 가장자리가 검게 번지며 흐려짐, 뒤 배경 살짝 흐림 (흰 테두리 없음)
  - 위아래 여백은 아주 조금, 좌우는 넉넉하게
  - 글: 흰색, 가운데 정렬, 작고 얇게 (14px, 얇은 두께), 글이 들어가는 폭은 최대 560px
  - 선택지(1. 들어간다 2. 물러난다 등)는 글 오른쪽에. 선택지가 없을 때는 오른쪽에 작은 X(닫기)
  - 지나간 글은 [시스템] 채팅에 남는다

### 아래 줄
- **채팅 탭**: [서버] [지역] [시스템]. 보낼 채널은 지역/서버. ("전체" 채팅은 "서버"로 부른다.)
- **행동 버튼**: 그 장소에서 할 수 있는 일 (이동, 둘러보기, 토벌 목록, 상점 등). 한 줄에 3개씩 타일.
  - **이동**을 누르면 버튼들이 출구 목록 타일로 바뀌고, [뒤로]로 돌아온다. 이동 버튼을 맵 위에 두지 않는다 (잘못 누르기 쉽고 방향이 헷갈림).
  - 토벌 이벤트가 있는 곳에서는 빨간 **토벌 입장** 버튼. 누르면 바닥 글 상자에 선택지가 뜬다.

## 전투 화면 (PC) — 2026-10-19 확정

### 전투 전경
- **왼쪽 위**: 맵 이름. **오른쪽 위**: `3라운드 · 이름의 차례 · 23초` 상자 (차례 부분은 노란 글씨).
- **가운데**: 적 이름 + `Lv`, 그 아래 적 HP 막대 (숫자는 안 보임), 그 아래 적 그림.
- **바닥 글 상자**: 전투 기록 최신 한 줄 (필드의 바닥 글 상자와 같은 모양).
- **참가자 컷**: 전경 양옆에 사다리꼴 컷. **좌 우 좌 우** 순서로 놓는다.
  - **1~2명**: 한쪽에 컷 하나씩 길게. **반신 컷인 이미지**가 위(얼굴)부터 컷을 꽉 채워 스킬 컷인처럼 드러난다.
  - **3~4명**: 한쪽에 위아래 두 칸씩 짧게. **정사각형 프사**가 컷 아래쪽에 들어간다.
  - **이름**: 컷 아랫면 경계에 걸쳐서, 크게 굵게 테두리 글씨. 내 캐릭터는 `이름 (나)`.
  - **HP**: 막대가 따로 없다. 줄어든 HP만큼 **사진 아래에서부터 붉은 반투명 그라데이션**이 차오른다 (항상 사진 위에 덮임). MP는 전경에 표시하지 않는다.
  - **쓰러짐**: 글씨 없이 사진이 흑백·어둡게.
  - **지금 차례인 사람**: 컷 테두리가 두꺼운(4px) 노란 빛으로 바뀌고, 하얗게 빛나는 작은 점 하나가 테두리를 따라 LED처럼 돈다. 차례가 아닌 사람은 테두리 없음.
  - **말풍선**: 전투 채팅에 쓴 말이 그 사람 컷 옆(가운데 쪽)에 5초간 뜬다.

### 아래 줄
- **채팅**: [전투 채팅] 탭 하나. 전투 참가자끼리만 보인다.
- **행동 버튼** (방어는 없음):

  ```
  ┌──────────────┐ ┌─────────┐
  │     스킬     │ │  공격   │   윗줄 높이 2/3  (스킬 : 공격 폭 = 3 : 2)
  │              │ │         │
  └──────────────┘ └─────────┘
  ┌─────────────────────┐ ┌──┐
  │        아이템        │ │도주│ 아랫줄 높이 1/3 (도주는 정사각형, 오른쪽 아래 끝.
  └─────────────────────┘ └──┘                    아이템이 남은 폭을 다 채움)
  ```
  - 도주는 흐린 색으로 다른 버튼보다 눈에 덜 띄게.
  - **스킬**을 누르면 버튼들이 내 스킬 목록 타일로 바뀌고, [뒤로]로 돌아온다.
  - **내 차례가 아니면** 모든 버튼이 흐려지고 눌리지 않는다.

## 아직 정하지 않은 화면
장비 · 인벤토리 · 스테이터스 · 프로필 창, 파티 · 친구 창, 폰 화면.

## 아직 정하지 않은 규칙
- 방어 버튼이 없어졌으므로, 차례 시간이 다 되면 자동으로 무엇을 할지 (지금 게임은 시간 초과 시 자동 방어).
