## 2. 접속 · 계정 · 관리자

- **회원가입**: 닉네임 + 비밀번호 + **초대 코드**. 초대 코드 하나로 계정 하나만 만들 수 있다 (이미 쓴 코드는 거절).
- **로그인**: 닉네임 + 비밀번호만. 초대 코드는 처음 가입할 때만 필요하다.
- **연결이 끊기면**: 30초 동안 캐릭터가 그 자리에 남는다. 그 안에 다시 들어오면 그대로 복귀(전투 중이었으면 전투 화면으로).
- **서버가 업데이트되면**: 접속해 있던 화면이 알아서 새로고침되고 같은 캐릭터로 돌아온다.
- **관리자 계정**: 닉네임 `admin`. Render 환경 변수 `ADMIN_CODE`를 초대 코드 칸에 적어야만 가입된다.
- **관리자 모드** (관리자 계정에서 **Ctrl + `**, 숫자 1 왼쪽 키)
  - [+ 초대 코드 만들기]: 한 번 누를 때마다 1개 (`XXXX-XXXX` 모양)
  - 코드 목록: 만든 때, 사용 여부, 가입한 계정 이름 · 시각, 복사 버튼

## 3. 캐릭터

**만들 때 고르는 것**

| 항목 | 선택지 |
| --- | --- |
| 성별 | 마법소녀 / 마법소년 |
| 속성 | 화염 🔥 · 물 💧 · 자연 · 빛 · 암흑 · 번개 · 얼음 (+ 물리: 일반 공격용) |
| 클래스 | 공격형(어태커) · 방어형(가디언) · 지원형(서포터) |
| 계약 신 | 힘의 신 · 마력의 신 · 생명의 신 · 바람의 신 · 행운의 신 (해당 스탯 +3) |

- **클래스 보너스**: 어태커 STR+2 MAG+2 / 가디언 VIT+4 / 서포터 MAG+2 LUK+2
- **기본 스탯**: STR · MAG · VIT · AGI · LUK 모두 5
- **시작할 때**: 100골드, 회복 사탕 3개, 견습 장비 3개(마법봉 · 리본 · 브로치)를 끼고 본부 광장에서 시작
- **성장**: 필요 경험치 50 × 현재 레벨, 최대 30레벨. 레벨업마다 스탯 포인트 3점 + HP/MP 전체 회복
- **계산식**: 공격력 STR×2+레벨 / 마법 공격력 MAG×2+레벨 / 방어력 VIT×1.5+레벨 (민첩은 차례 순서 · 회피에)
- 계정당 캐릭터 최대 5명, 캐릭터 변경 · 삭제 가능

## 4. 맵 · 이동 · 채팅

**지역과 구역**

| 지역 | 권장 레벨 | 구역 |
| --- | --- | --- |
| 본부 (안전지대) | - | 본부 광장 · 복구의 여신 신전 · 상점 · 퀘스트 게시판 |
| 공원 균열 | 1~10 (자연) | 공원 입구 · 산책로 · 분수 광장 · 숲길 · 호숫가 · 균열의 중심 |

- 버튼으로 이웃 구역으로 이동, 지도 보기, 지역마다 배경색이 다르다.
- 본부에 들어가면 HP/MP 전체 회복.
- 같은 구역에 있는 사람 목록(자리 비움 · 전투 중 표시), 화면 아래에 접속자 수.
- **채팅**: 전체 · 지역 · 전투 · 시스템 탭. 탭을 눌러 그 종류를 켜고 끈다. 너무 빨리 보내면 잠깐 막힌다.
- 채팅 기록은 서버에 최근 것만 잠깐 기억한다 (전체 50개, 지역마다 30개). 쌓이지 않는다.

## 5. 전투

**토벌 이벤트**: 지금은 테스트용 상시 토벌 하나 — **공원 균열 › 균열의 중심**의 **덩굴 포식자**. 잡아도 다시 나타난다.

**진행 방식**
- 턴제. 민첩(AGI) 높은 순으로 차례가 온다. 민첩이 같으면 전투에 들어올 때 정한 무작위 순서를 끝까지 지킨다.
- 내 차례에 **공격 / 스킬 / 아이템 / 도주**. **차례 제한시간 없음** (자동으로 넘어가지 않는다).
- 한 전투에 최대 4명. 진행 중에도 합류할 수 있다 (다음 라운드부터 행동).
- 연결이 끊긴 사람은 30초 뒤 전투에서 빠진다.
- **혼자 / 파티 같이 입장**: 파티원이 모두 같은 장소에 있으면 [같이] 입장을 고를 수 있다. 30초 안에 모두 수락하면 다 같이 1라운드부터 시작, 한 명이라도 거절하면 취소.

**판정**
- 데미지: (공격력 × 위력 − 방어력 × 0.5) × 속성 배율 × 난수(0.9~1.1), 최소 1
- 몬스터 속성 저항: 취약 ×1.5 / 내성 ×0.5 / 면역 ×0
- 회피, 치명타(×1.5)
- 몬스터 AI: 도발한 사람 → 가장 많이 때린 사람 또는 무작위. 몇 턴마다 강한 특수 공격.
- 승리: 경험치 · 골드는 참가 인원수로 나눔, 아이템은 각자 따로 드롭 확률을 굴린다.
- 전멸: 본부로 옮겨지고 보유 골드 10% 손실 (이벤트는 그대로 남음).

**전투 화면 연출**
- 위에 적 이름 · 레벨 · HP 막대, 가운데 적 그림
- 양옆에 참가자 컷 (1~2명: 반신 컷인 사진, 3~4명: 정사각형 프사). 맞으면 아래부터 붉게 차오른다.
- 지금 차례인 사람: 사진 바깥에 노란 빛 테두리 + LED처럼 도는 하얀 점
- **데미지 숫자**: 몬스터 근처 무작위 위치에서 떠올랐다 사라짐. 공격 속성 색, 치명타는 크게, 약점 · MISS · 면역 표시
- 대사 프리셋과 전투 채팅은 그 사람 컷 옆 말풍선으로 뜬다.

## 9. OC 프로필

- **사진 2장**: ① 정사각형 프사 (채팅 · 프로필 카드 · 3~4명 전투) ② 세로로 긴 반신 컷인 (1~2명 전투 · 프로필 창)
- **이름**: 다른 캐릭터와 겹치지 않게 (중복 확인)
- **칭호**: 얻은 칭호 중 하나를 이름 아래에 단다. 지금 칭호: [견습 계약자](처음부터), [첫 토벌의 증인](첫 토벌 승리)
- **성별 · 속성 · 클래스** 표시, **설정 글** 2000자까지
- **관계**: 친구에게 관계 이름(12자까지)을 붙이면 두 사람 프로필에 다 보인다. 5줄이 넘으면 스크롤.
- **대사 프리셋**: 상황 7가지(전투 시작 · 공격 · 스킬 · 다침 · 회복받음 · 쓰러짐 · 승리), 상황마다 3개, 한 줄 40자. 전투에서 그 상황이 오면 무작위로 하나를 말풍선으로 말한다.
- 채팅의 이름이나 목록에서 다른 사람 프로필을 열어 볼 수 있다.

## 10. 친구 · 관계 · 파티

**친구**
- 이름으로 신청 → 상대가 수락하면 친구 (오프라인이어도 신청은 남는다. 서로 신청하면 바로 친구)
- 친구 목록: 접속 여부 · 위치 · 전투 중 빨간 점, 받은 신청 / 보낸 신청
- 친구를 끊으면 관계도 같이 없어진다

**파티** (친구 창과 같은 창, 위쪽 [친구] [파티] 탭)
- 파티장이 접속 중인 사람을 초대 → 받은 사람에게 팝업 [수락] / [거절]
- 파티장: 추방 · 위임 · 파티 이름 바꾸기(설정 아이콘). 누구나 나가기 (내 이름 우클릭)
- 필드 화면 왼쪽 위(맵 이름 아래)에 파티원 목록: 이름 · 위치 · 전투 중 표시
- 파티는 서버 메모리에만 있다 (서버가 다시 켜지면 사라짐)

**팝업 규칙**: 모든 팝업은 바깥을 눌러도 닫히지 않고 `×`·Esc로만 닫힌다. 파티 초대 · 같이 토벌 입장 창의 `×`·Esc는 거절(시작한 사람은 취소).

## 12. 서버 · 배포

| 항목 | 내용 |
| --- | --- |
| 게임 서버 | Render 무료 (싱가포르). 15분 동안 아무도 없으면 잠든다 → UptimeRobot으로 `/health`를 5분마다 두드려 깨워 둔다 |
| 데이터베이스 | Supabase (Postgres), Session pooler 주소로 연결 |
| Render 환경 변수 | `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_CODE` |
| 버틸 수 있는 인원 (어림) | 동시 접속 20~50명 |
| 게임 데이터 | `server/data/*.json` (캐릭터 · 스킬 · 아이템 · 몬스터 · 맵 · 상점 · 이벤트). 수치는 여기서 바꾼다 |
| 자동 테스트 | `npm test` (30개) |

알아 둘 점: 전투 도중에 서버가 다시 켜지면 그 전투는 사라지고, 캐릭터는 전투 들어가기 전 상태로 돌아간다.
